# Tattoo Studio Website — Delivery Workflow

## Stage 1 — Lead

- Send concise outreach.
- Show the live demo only after interest.
- Confirm whether the studio needs the standard website or additional functionality.

## Stage 2 — Scope & Payment

- Confirm price and included features in writing.
- Collect 50% upfront payment.
- Send CLIENT_ONBOARDING.md.
- Do not start full customization until required assets begin arriving.

## Stage 3 — Client Build

1. Duplicate this repository for the client.
2. Update site-config.js with the real studio details.
3. Replace Nocturne branding and logo.
4. Replace all placeholder photography.
5. Replace artist profiles.
6. Replace testimonials only with genuine approved reviews.
7. Update booking, deposit and FAQ wording.
8. Connect real WhatsApp and email.
9. Add client domain metadata / canonical URLs.
10. Verify all pages on desktop and mobile.

## Stage 4 — Internal QA

Check:

- Navigation
- Mobile menu
- WhatsApp
- Email links
- Booking form
- Gallery lightbox
- Artist links
- Contact details
- Address and map link
- Spelling
- Image quality
- Page titles / descriptions
- Canonical URL
- Favicon
- 404 page
- Domain HTTPS

Never use fake testimonials or placeholder contact details in production.

## Stage 5 — Client Review

Send one review URL.

Ask the client to verify factual information, portfolio choices and branding. Consolidate requested corrections into the included revision round.

Avoid making unrelated redesigns during final review unless they are separately scoped.

## Stage 6 — Final Payment

Once the client approves the production-ready build:

- Request remaining 50%.
- Do not transfer ownership / final production handoff before payment clears unless previously agreed in writing.

## Stage 7 — Production Launch

- Connect domain.
- Run final URL checks.
- Verify SSL / HTTPS.
- Test on a real mobile device.
- Test consultation journey from homepage to contact.
- Confirm client can receive inquiries.

## Stage 8 — Handoff

Provide:

- Live website URL
- Repository / source ownership arrangement agreed with client
- Basic instructions for contacts / assets
- Maintenance-plan option
- List of any external services the client owns and pays for

## Maintenance Boundary

₹1,500/month covers small routine changes described in BUSINESS_PACKAGE.md.

Anything that materially changes architecture, design, integrations or page count is separately scoped.
