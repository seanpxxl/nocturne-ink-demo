# Tattoo Studio Website — Client Package

## Core Offer

A premium, mobile-first website for tattoo studios designed to showcase work, build trust and convert visitors into consultations.

## Launch Package — ₹10,000

Includes:

- Custom studio branding adaptation
- Mobile-first responsive design
- Homepage
- Artists page
- Gallery page with lightbox
- Booking / consultation page
- Contact page
- WhatsApp CTA integration
- Real studio email integration
- Studio hours and address
- Client testimonials section
- FAQ section
- Deposit / booking process explanation
- Basic SEO metadata
- Social sharing metadata
- Favicon
- GitHub Pages or static-host deployment
- Custom domain connection support
- One round of post-build content corrections

## Client Supplies

- Studio logo
- Brand colors, if any
- Artist names, photos and specialties
- Tattoo portfolio images
- WhatsApp number
- Email address
- Studio address
- Instagram link
- Working hours
- Verified client reviews
- Booking / deposit rules
- Domain access if they already own one

## Not Included in ₹10,000

Quoted separately if required:

- Domain purchase
- Paid hosting
- Custom backend / dashboard
- Online payments
- Advanced appointment calendar integration
- Copywriting from scratch for a large website
- Professional photography
- Complex e-commerce
- More than the included revision round

## Maintenance — ₹1,500 / month

Suggested recurring care plan:

- Up to 3 small content updates per month
- Artist / portfolio image changes
- Contact and timing updates
- Basic link and form checks
- Minor text changes
- Deployment support
- Backup of current production files

Major redesigns, new pages, new systems or large gallery uploads are quoted separately.

## Payment Structure

Recommended:

- 50% upfront to begin
- 50% before final production launch / domain handoff

Do not begin full customization without the upfront payment and required client assets.

## Delivery Target

Typical target after all assets and information are received: 5–7 business days.

The timeline pauses when required client content or approvals are missing.

## Positioning

Do not sell this as “a few HTML pages.” Sell the outcome:

> A premium mobile-first website that makes the studio look established, showcases its strongest work and gives potential clients a clear path to book a consultation.
