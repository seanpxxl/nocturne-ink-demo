# Nocturne Ink Demo

A mobile-first dark luxury tattoo studio website concept for Chennai.

## Current build

- Responsive one-page homepage
- Dark gothic / luxury art direction
- Tattoo style showcase
- Fictional artist roster
- Selected-work gallery
- Consultation process
- Booking CTA + WhatsApp placeholder
- Mobile navigation and scroll-reveal interactions

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.
