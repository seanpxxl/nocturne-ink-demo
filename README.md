# Nocturne Ink Demo

A mobile-first dark luxury tattoo studio website template built as a sellable demo concept for Chennai.

## Live demo

https://seanpxxl.github.io/nocturne-ink-demo/

## Current build

- Multi-page responsive website
- Dark gothic / premium art direction
- Homepage conversion flow
- Dedicated Artists page
- Masonry Gallery with interactive lightbox
- Consultation / Booking page
- Contact page
- Sticky WhatsApp placeholder CTA
- Mobile quick-book bar
- Testimonials, FAQ and deposit guidance
- Scroll reveals, hover polish and responsive navigation
- Open Graph metadata, sitemap and robots.txt
- Custom favicon
- Automatic GitHub Pages deployment from `main`

## Pages

- `index.html` — Homepage
- `artists.html` — Artist roster and profiles
- `gallery.html` — Tattoo portfolio
- `booking.html` — Consultation request
- `contact.html` — Studio contact information

## Client conversion checklist

Before delivering this template to a real studio:

1. Replace **Nocturne Ink** with the real studio brand.
2. Replace all demo / Unsplash imagery with client-owned or properly licensed images.
3. Replace fictional artist names, biographies and specialties.
4. Replace `hello@nocturneink.demo` with the studio email.
5. Replace `910000000000` in WhatsApp links with the real number including country code.
6. Replace sample testimonials with verified customer reviews.
7. Replace placeholder address, opening hours and Instagram information.
8. Connect the booking form to the client's preferred service or CRM.
9. Add the client's custom domain only after final approval.
10. Recheck mobile layout, links, SEO metadata and form submissions before handoff.

## Structure

- `styles.css` — core visual system and page layouts
- `phase3.css` — conversion/trust layer styling
- `phase4.css` — premium interaction and mobile polish
- `script.js` — navigation, reveals, WhatsApp CTA, favicon, lightbox and mobile booking bar
- `.github/workflows/deploy-pages.yml` — automatic deployment
