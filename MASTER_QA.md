10. Real booking submission destination
11. Client domain
12. Analytics / Search Console ownership

## Freeze rule
Do not keep adding features to the master demo merely because they are possible. New features should be added only when they improve sales conversion, solve a repeated client need, or are part of a paid custom scope.

The master is now ready to duplicate for real tattoo-studio projects.
